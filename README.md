# ECE 285 Homeworks

Repository: [moose1108/ece285-homeworks](https://github.com/moose1108/ece285-homeworks)

Code, experiment configurations, and results for ECE 285 homework assignments. Each assignment has its own directory.

| Assignment | Topic | Contents |
| --- | --- | --- |
| [HW1](HW1/) | Variational Autoencoder | Chest X-ray generation, pure VAE training and evaluation, result figures, and report |

Add subsequent assignments as `HW2/`, `HW3/`, and so on, and update this index.

Write all READMEs and specifications in English.

Datasets, model weights, virtual environments, and caches are excluded from Git. See each assignment's README for setup instructions and the requirements for reproducing recorded results.
